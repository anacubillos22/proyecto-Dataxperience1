# Proyecto Final: Ciencia de Datos en Acción

Repositorio oficial para el proyecto final del curso de Ciencia de Datos, donde se integran los fundamentos de preparación de datos, análisis estadístico y modelado predictivo utilizando Python.

---

## Tecnologías y Librerías Utilizadas
* Python (Lenguaje principal de programación)
* Pandas y NumPy (Manipulación y limpieza de datos)
* Matplotlib y Seaborn (Visualización gráfica y estadística)
* Scikit-Learn (Implementación de modelos predictivos)

---

## Estructura del Repositorio
* `Data/dataset_limpio.csv`: Contiene el conjunto de datos depurado tras la fase de preprocesamiento.
* `Proyecto Final.py`: Script principal que automatiza las tres etapas del proyecto.

---

## Fases del Proyecto

### 1. Módulo 1: Fundamentos y Preparación de Datos
* **Selección del escenario:** Se diseñó un entorno de análisis enfocado en el rendimiento académico y factores de estudio.
* **Exploración y Limpieza:** Se identificaron y trataron valores nulos y registros duplicados para asegurar la integridad de la información antes del análisis.

### 2. Módulo 2: Análisis Estadístico
* **Estadística Descriptiva:** Cálculo de medidas de tendencia central (media, mediana) y dispersión (desviación estándar).
* **Detección de Outliers:** Generación de gráficos de caja (boxplots) para identificar valores atípicos y comportamientos excepcionales dentro de las variables.

### 3. Módulo 3: Visualización, Modelado Predictivo y Conclusiones
* **Visualización de Datos:** Creación de diagramas de dispersión (scatterplots) para evidenciar correlaciones directas entre variables.
* **Modelo Predictivo:** Entrenamiento de un modelo de Regresión Lineal Simple para estimar comportamientos futuros, evaluando su precisión mediante el puntaje de determinación (R²).
* **Aplicación Profesional:** Demostración de cómo estas herramientas analíticas permiten la toma de decisiones basada en datos dentro de entornos técnicos y profesionales.
